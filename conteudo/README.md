# Conteúdo de e-books

Os três modelos de e-book aceitos são PDF, EPUB e HTML.

Esta é a fonte editorial oficial do projeto. Mantenha-a vazia até que cada item tenha passado por revisão e recebido aprovação explícita do usuário. Arquivos em `Plano e Ideias/arquivos variados/` são apenas referências e não devem ser importados automaticamente.

Guarde cada arquivo na pasta correspondente:

- `PDFs/` — arquivos no formato PDF.
- `EPUBs/` — arquivos no formato EPUB.
- `HTML/` — arquivos e pacotes no formato HTML.

Fluxo de entrada: **revisão → aprovação explícita → cópia rastreável para a pasta do formato correspondente**. Preserve a origem e registre a decisão em `documentacao/`.
